# Four-minute demo

1. Open the app in demo mode. Point out the explicit simulation notice and the sample reports. Switch to Tamil and start a new report; plain text input works in either language.
2. Report a pothole near a Chennai school, answer location/duration/impact, review the category and set road ownership to municipal if that is the scenario. Otherwise show that unknown ownership routes to the triage desk. Add an optional photograph, consent and submit.
3. Open the saved case to show its tracking reference, department, severity panel and submission event (AI assessment is unavailable in browser-only demo). Evidence shows its hash and the honest “authenticity unverified” assessment.
4. Open Official dashboard → GCC Roads. Acknowledge the case, add a work assignment note, start work and upload a completion photograph. Submit resolution. These are fictional department accounts.
5. Return to My reports. Appeal with a reason. Switch back to the officer, resume work and upload fresh evidence, then resolve again. Return as citizen and confirm closure. There is no second appeal.
6. Reload: metadata and attachments persist in this browser. Download the report JSON or use Print / save PDF. Explain that connected mode replaces browser persistence with Supabase Auth, private storage, RLS and transactional append-only events.

OpenRouter is used only in configured, authenticated connected mode. Demo mode uses the deterministic guided interview. The app does not contact government agencies or claim to prove uploaded media is genuine.
